# 성진 클래스 잠원점 v0.8

- 첫 번째 UI 시안의 구조를 기준으로 아이스 블루·네이비 GNB를 적용했습니다.
- 데이터 조회는 `academy_shared_data`의 `cf.students`를 직접 조회합니다.
- 학생이 0명인 경우 실제로 없는지, RLS 때문에 가려지는지를 배너에서 안내합니다.
- 엑셀 백업은 기존 기능을 유지합니다. 출석·교육비 원본은 자동 업무 변환이 완료되지 않았습니다.

`npm install && npm run build`로 로컬 검증하세요. Google OAuth와 Supabase 실연동 테스트는 이 환경에서 수행하지 못했습니다.
