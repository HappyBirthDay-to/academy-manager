# ClassFlow 관원 관리 웹앱 (시제품 v0.1)

원본 엑셀의 **현황판 / 출석부 / 차량 스케줄 / 교육비** 화면을 참고한 첫 번째 웹앱 시제품입니다.

## 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

## Render 무료 Static Site 배포

1. GitHub에서 **Private** 저장소를 생성합니다.
2. 이 폴더의 파일을 저장소에 올립니다. 실제 학생정보는 올리지 마세요.
3. Render > New > Static Site에서 저장소를 연결합니다.
4. Build Command: `npm install && npm run build`, Publish Directory: `dist`를 지정합니다.
5. 배포 후 생성된 주소로 접속합니다.

## 현재 구현 범위

- 학생 등록·수정·삭제·검색
- 요일/시간별 수업 시간표 자동 배치 (`월2 수2 금2` 형식)
- 월별 출석/결석/보강 기록
- 등하원 차량 장소 및 시간 조회
- 월별 교육비 완납/미납/면제 상태 기록
- 학생/출석/교육비 데이터 엑셀 내보내기
- 대시보드 집계, 모바일 대응

## 중요 제한사항

- **원본 엑셀의 수식·서식·매크로를 100% 재현한 완성품이 아닙니다.** 4개 화면을 바탕으로 한 초기 시제품입니다.
- 원본 엑셀 자동 가져오기, 수업 횟수·차량 운행의 상세 규칙, 수납 금액 계산은 검증 후 추가해야 합니다.
- 데이터는 **현재 브라우저 localStorage에만 저장**됩니다. 다른 기기와 동기화되지 않고 브라우저 데이터 삭제 시 소실될 수 있습니다. 정기적으로 엑셀 백업하세요.
- **로그인과 서버 데이터베이스가 없으므로 실제 개인정보를 넣어 운영하지 마세요.** Render에 올려도 개인정보를 안전하게 공유하는 서비스가 되는 것은 아닙니다.
- 실제 운영 버전에는 사용자 인증, 접근권한, 데이터베이스, 백업·복원, 감사 기록이 필요합니다.
